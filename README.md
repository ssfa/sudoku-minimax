# Sudoku Minimax

스도쿠 퍼즐 앱 (안드로이드)

## 버전

- **현재**: 0.0.1 (versionCode 1)

## 빌드

```bash
mise run build
```

APK: `artifacts/ssfa.sudoku.minimax-0.0.1.apk`

## 기능

- 3단계 난이도 (하/중/상)
- 힌트 / 메모 기능
- 타이머
- 저장/복원
- 라이트/다크 테마

## 개발

```bash
mise run build          # 디버그 APK
mise run install        # 기기 설치
mise run launch         # 실행
```
